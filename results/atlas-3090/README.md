# Atlas RTX 3090 Notes

This directory is reserved for local CUDA sanity notes from Atlas (`RTX 3090`).

It is **not** evidence for the SYCL Turbo path and should not be used for B70
performance claims or non-B70 SYCL regression claims. The useful non-B70 test
would require another Intel SYCL-capable GPU and a control-vs-Turbo SYCL run.

Raw Atlas run directories are local-only by default.
